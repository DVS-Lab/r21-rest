R21 Resting-State Network Coupling Report¶

Final N=27 report for coupling among the original 10 Smith09 networks. It presents only DMN coupling with ECN, left FPN, and right FPN. Full correlations are ordinary Pearson correlations; partial correlations control the other eight Smith09 timecourses through the precision matrix.

Condition inference is restricted to the same three nonredundant contrasts used in the primary report. The secondary DMN x ECN physio-physio interaction (PPI) analysis uses the original 10-map model. Unrelated-network analyses are intentionally excluded.

def project_path(value):
    path = Path(str(value))
    return path if path.is_absolute() else PROJECT_ROOT / path


def signed_effect(contrast, direction):
    first, second = CONTRAST_TERMS[contrast]
    if str(direction).lower() == 'negative':
        first, second = second, first
    return f'{first} > {second}'

CONTRAST_WEIGHTS = {
    'mean-stimulation-minus-sham': {'sham': -1.0, 'rtpj': 1/3, 'vlpfc': 1/3, 'both': 1/3},
    'both-minus-mean-rtpj-vlpfc': {'rtpj': -0.5, 'vlpfc': -0.5, 'both': 1.0},
    'rtpj-minus-vlpfc': {'rtpj': 1.0, 'vlpfc': -1.0},
}


def signflip_p(values, n_perm=100000, seed=20260806):
    values = np.asarray(values, dtype=float)
    observed = float(values.mean())
    rng = np.random.default_rng(seed)
    signs = rng.choice((-1.0, 1.0), size=(n_perm, len(values)))
    permutation_means = signs @ values / len(values)
    return float((np.count_nonzero(np.abs(permutation_means) >= abs(observed)) + 1) / (n_perm + 1))


contrast_records = []
seed_index = 0
for pair in TARGET_PAIRS:
    for corr_type in ['full', 'partial']:
        subset = focused[focused['network_pair'].eq(pair) & focused['correlation_type'].eq(corr_type)]
        pivot = subset.pivot(index='participant', columns='condition', values='fisher_z').reindex(columns=CONDITIONS)
        assert pivot.shape == (27, 4) and not pivot.isna().any().any()
        for contrast in CORE_CONTRASTS:
            weights = CONTRAST_WEIGHTS[contrast]
            delta = sum(pivot[condition] * weight for condition, weight in weights.items())
            mean = float(delta.mean())
            sem = float(delta.std(ddof=1) / np.sqrt(len(delta)))
            contrast_records.append({
                'Pair': PAIR_LABELS[pair],
                'Correlation': corr_type,
                'Contrast': CONTRAST_LABELS[contrast],
                'N': len(delta),
                'Mean delta Fisher z': mean,
                'SEM': sem,
                'Two-sided sign-flip p': signflip_p(delta, seed=20260806 + seed_index),
            })
            seed_index += 1

contrast_audit = pd.DataFrame(contrast_records)

ppi['one_sided_p'] = 1.0 - ppi['peak_corrp']

ppi_audit = []
ppi_winners = []
for contrast in CORE_CONTRASTS:
    subset = ppi[ppi['condition_contrast'].eq(contrast)]
    if subset.empty:
        ppi_audit.append({
            'Contrast': CONTRAST_LABELS[contrast],
            'Strongest direction': 'missing from PPI summary',
            'Best one-sided FWE p': np.nan,
            'Conservative two-sided p': np.nan,
            'Result': 'missing',
        })
        continue
    assert set(subset['direction']) == {'positive', 'negative'}
    winner = subset.sort_values('one_sided_p').iloc[0]
    two_sided_p = min(1.0, 2.0 * float(winner['one_sided_p']))
    ppi_audit.append({
        'Contrast': CONTRAST_LABELS[contrast],
        'Strongest direction': signed_effect(contrast, winner['direction']),
        'Best one-sided FWE p': float(winner['one_sided_p']),
        'Conservative two-sided p': two_sided_p,
        'Result': 'significant' if two_sided_p < .05 else 'null',
    })
    if two_sided_p < .05:
        ppi_winners.append((winner, two_sided_p))

Interpretation¶

  • DMN–left-FPN coupling is negative in every condition. DMN–right-FPN coupling is near zero during sham and generally negative during active stimulation. DMN–ECN coupling is weakly positive.
  • None of the 18 full/partial correlation tests across the three prespecified contrasts reaches nominal two-sided p<.05. The signs therefore characterize baseline network relationships, not reliable stimulation-related changes in global coupling.
  • The secondary 10-map DMN×ECN PPI shows VLPFC > RTPJ (conservative two-sided p=.0368) and BOTH > mean(RTPJ,VLPFC) (p=.0496).
  • The completed mean-stimulation-versus-sham PPI contrast is null (best one-sided FWE p=.9398; conservative two-sided p=1.0000).

The global correlations and voxelwise PPI answer different questions. Correlations summarize whole-network timecourse coupling, whereas PPI identifies voxels whose association with the DMN-by-ECN interaction differs by condition. PPI bars are descriptive summaries from the same corrected clusters, not independent ROI tests. Unrelated-network analyses do not contribute to this report.

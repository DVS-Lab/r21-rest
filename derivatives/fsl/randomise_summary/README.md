# Randomise Summary

Generated by `code/check_randomise_results.py`. FSL corrected-p images store
`1-p`; values greater than 0.95 therefore correspond to one-tailed corrected
p-values below 0.05. By default, the TSV contains cluster-extent maps for
positive (C1) and negative (C2) directions; TFCE is included only when
explicitly requested. NIfTI files and JSON sidecars are copied here only when
the map is complete and its peak exceeds the configured threshold. Each copied
map also has a small participant-by-condition stage-2 beta TSV for portable
notebook plotting.

The final shareable report restricts presentation to the original 10-map
Smith09 DMN and ECN results and the three prespecified nonredundant contrasts.

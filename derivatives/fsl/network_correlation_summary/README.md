# Network Correlation Summary

Generated by `code/MakeNetworkCorrelationTables.py` from dual-regression
stage-1 timecourse files. The run-values table contains Pearson full
correlations and precision-matrix partial correlations among Smith09 network
timecourses. The condition-contrast table applies within-participant
condition contrasts to Fisher-z-transformed correlations. The summary table
reports one-sample means and deterministic Monte Carlo sign-flip p-values.

The final shareable report uses the original 10-map model and focuses on DMN
coupling with ECN, left FPN, and right FPN across the three prespecified
nonredundant contrasts.
